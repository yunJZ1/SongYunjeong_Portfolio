## Purpose

The homepage is the landing experience of Yunjeong Song's portfolio.

Instead of introducing the designer through a traditional portfolio layout, the homepage should feel like an AI-native product where visitors naturally explore projects through conversation.

The homepage should introduce the designer, showcase featured work, and guide users toward detailed case studies and publications.

---

# Homepage Goals

The homepage should help visitors:

- Understand who Yunjeong Song is.
- Experience an AI-native interaction.
- Quickly discover featured projects.
- Browse publications.
- Continue into detailed case studies.

The homepage should prioritize exploration over explanation.

# Hero

The Hero is the primary interaction area.

It should occupy approximately 70–80% of the first viewport.

The Hero contains:

- Main Heading
- Prompt Input
- Quick Prompt Chips

All content is horizontally centered.

The Hero should create generous whitespace.

---

## Hero Heading

The heading should immediately communicate:

# Homepage Navigation

The homepage does NOT contain a left-side navigation.

A sticky Table of Contents is only used inside individual Case Study pages.

---

# Left Navigation

The homepage uses a fixed left-side navigation on desktop.

This navigation should feel like simple text links, not a sidebar component.

Contains:

- How I Work
- Case Study
- Publications
- Who am I

Style rules:

- No surrounding box.
- No border.
- No rounded container.
- No background panel.
- No card treatment.
- Text-only.
- Active item may use bold weight or subtle opacity change.
- Hidden on mobile.

The main content area must have enough left offset so it does not overlap with the navigation.

# Homepage Principles

The homepage should resemble an AI product rather than a traditional portfolio website.

Prioritize

- whitespace
- typography
- conversation
- discoverability

Avoid

- dashboard layouts
- unnecessary borders
- excessive cards
- boxed sidebar navigation

Sections should be separated primarily through whitespace rather than borders.
