# Portfolio Design System

## Goal

This portfolio follows an editorial case study layout rather than a dashboard or product UI.

The content should feel like reading a design article.

Every project must follow the same layout and typography.

---

## Desktop Layout

Viewport: 1440px+

Container Width: 1200px

Reading Width: 760px

Left Navigation Width: 180~220px

Navigation remains sticky.

---

## Typography

Hero Title

Large and dominant.

Section Heading

Clearly separated from body text.

Body

Optimized for long-form reading.

Meta

Small and subtle.

---

## Vertical Rhythm

Large spacing between sections.

Generous whitespace.

Images should breathe.

---

## TL;DR

Display as an editorial summary.

Avoid card-heavy styling.

---

## Metrics

Large numbers.

Minimal styling.

No heavy cards.

---

## Images

Large.

Border radius only.

No shadow.

---

## Case Study Rule

Every case study should use exactly the same:

- content width
- typography scale
- spacing
- navigation
- section rhythm

Only the content changes.
